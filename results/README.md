# Resultados

Esta carpeta contiene los resultados generados durante la ejecución del pipeline experimental.

La carpeta figures/ contiene las gráficas generadas a partir de los experimentos:

comparación MAE/RMSE en el escenario base;
evolución del MAE bajo ruido gaussiano y pérdida de puntos de acceso;
evolución del RMSE bajo ruido gaussiano y pérdida de puntos de acceso;
distribución del error espacial;
heatmap de MAE;
comparación espacial entre posiciones reales y estimadas;
tiempos de entrenamiento y validación.

La carpeta processed/ contiene archivos intermedios utilizados para almacenar resultados numéricos, escaladores y matrices procesadas durante la ejecución del pipeline.
